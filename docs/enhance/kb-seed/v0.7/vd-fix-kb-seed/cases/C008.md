# C008 未使用的私有成员：加 unused 属性还是删掉

- **包**：united-service；19091860 中的 com.samsung.tv.aria-engine、org.tizen.picture-test 同类
- **告警标志**：[[Wunused-private-field]]
- **根因类别**：未用代码
- **是否真 bug**：非 bug

## 报错原文

日志原文（构建 19091860；由 LogAnalyzer 从失败日志提取的文件、行号和消息原文，未含列号；本机用户名已换成 `<USER>`）：

```
/home/<USER>/rpmbuild/BUILD/com.samsung.tv.aria-engine-3.005.05/inc/interface/SecureStorage.h:19: error: private field 'm_moduleID' is not used [-Werror,-Wunused-private-field]
/home/<USER>/rpmbuild/BUILD/org.tizen.picture-test-0.3/src/ResultView.h:26: error: private field 'm_pText' is not used [-Werror,-Wunused-private-field]
```

aria-engine 同一头文件第 19、21、22 行各一处；picture-test 另有 MessageView.h 第 24、26 行等。

## 解决方案（采用的修法）

按规则 R10：确实无用的成员不直接删，先注释掉并写明原因，真正删除由开发者决定；有 ABI 或将来使用理由的保留并加 `[[maybe_unused]]` / `__attribute__((unused))`。

## 备选与为什么没用

只对 Clang 加 `-Wno-unused-private-field`：最省事，但会让所有同类问题都被压掉。
