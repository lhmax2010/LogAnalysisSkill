# C012 GCC 专有编译选项被 Clang 拒绝

- **包**：（见来源）
- **告警标志**：[[unknown-argument]]
- **根因类别**：工具链选项
- **是否真 bug**：非 bug

## 报错原文

典型形式（Clang 的诊断格式，不是本库某次日志的原文；补到真实日志后替换）：

```
clang: error: unknown argument: '-fvar-tracking-assignments'
```

这是错误级诊断，不带 `[-W…]`，不能用 -Wno-… 关掉。

## 解决方案（采用的修法）

先查选项从哪来：来自 rpm 宏（如调试信息相关宏）就改 project_config 的宏；来自包自己的 Makefile 就在 spec 里按编译器条件处理（R08 写法）。

## 备选与为什么没用

`-Wno-unknown-warning-option` 等对"未知参数"无效；它是错误级诊断，不能用 -W 关掉。

## 需联动看的模块

- **头文件 / 接口 / 输入的提供者**：选项的来源：rpm 宏（project_config）或包自己的 Makefile——来自宏时要改 project_config，会影响所有用这个宏的包
- **下游（依赖这个包、改了会受影响的）**：来自宏时：所有用这个宏的包
