# C007 子类同名函数藏住父类虚函数（widget-viewer-dali）

- **包**：widget-viewer-dali
- **告警标志**：[[Woverloaded-virtual]]
- **根因类别**：C++ 可见性 / 事件分发
- **是否真 bug**：需看一眼

## 报错原文

典型形式（Clang 的诊断格式，不是本库某次日志的原文；补到真实日志后替换）：

```
<文件>:<行>: error: '<子类>::<函数>' hides overloaded virtual function [-Werror,-Woverloaded-virtual]
```

## 解决方案

- **类型**：通用做法（以往记录摘要；具体 CL、文件和修改前后摘要待补）。

只把信号回调改名（OnWheelEvent → OnWheelEventImpl）；不要新增 override。另一处模板推导失败用显式成员函数指针转换解决（与 dali-adaptor 自身写法一致）。

## 备选与为什么没用

原补丁新增了 `OnWheelEvent(const WheelEvent&) override` 加转发：能编过，但滚轮事件会被发两次；遥控器拨轮事件只走信号，不能被虚函数替代。

## 要点

"编过了"不等于对；这类修法必须读框架的事件分发代码。提交说明不要把编译器一致性差异写成"库 API 变了"。
