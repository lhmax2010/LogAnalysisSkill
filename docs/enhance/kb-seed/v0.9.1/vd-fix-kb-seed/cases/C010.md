# C010 C++ 里的变长数组改 std::vector

- **包**：ELF 解析代码（另有同类验收样本，见 packages/ 下的包页）
- **告警标志**：[[Wvla-cxx-extension]]
- **根因类别**：可移植性
- **是否真 bug**：非 bug（注意长度单位）

## 报错原文

典型形式（Clang 的诊断格式，不是本库某次日志的原文；补到真实日志后替换）：

```
<文件>:<行>: error: variable length arrays in C++ are a Clang extension [-Werror,-Wvla-cxx-extension]
```

## 解决方案

- **类型**：通用做法（以往记录摘要；具体 CL、文件和修改前后摘要待补）。
- 改成 `std::vector`，原数组长度的单位（字节还是元素个数）照原样保留。
- **原代码里对这个数组用 `sizeof(arr)` 的地方要全部改成 `arr.size() * sizeof(T)`**：改成 vector 后 `sizeof` 得到的是 vector 对象本身的大小，能编过，结果却错了。

## 备选与为什么没用

只对 Clang 加 `-Wno-vla-cxx-extension`：行为不变。
