# C009 引用有歧义（reference to X is ambiguous）

- **包**：（见来源）
- **告警标志**：（无对应告警标志）
- **根因类别**：C++ 名字查找

## 报错原文

典型形式（Clang 的诊断格式，不是本库某次日志的原文；补到真实日志后替换）：

```
<文件>:<行>: error: reference to '<名字>' is ambiguous
```

## 解决方案

- **类型**：通用做法（以往记录摘要；具体 CL 待补）。
- 先确定歧义来自哪些声明、走的是哪条名字查找路径。
- 同级命名空间也可以用 `A::name` 这样的限定名消歧（例：`using namespace A; using namespace B;` 之后 `value` 有歧义，写 `A::value` 即可，不需要改名）；继承、重载和 using 引入的歧义分别判断。
- 不能仅凭"同一层级"就决定改名；确实要改名时，先查调用关系和接口影响，转人工。

## 备选与为什么没用

不分情况自动"加 ::"或自动改名：同一诊断文字背后的符号结构不同，自动改可能改错对象或改遍全包——能编过但不该提交。
