# Decisions

| ID | Date | Decision | Source | Rationale | Impact |
| --- | --- | --- | --- | --- | --- |
| d001 | 2026-05-18 | Preserve both normalized `LogLine.text` and original `LogLine.raw_text`; add `gbs_seconds`. | Real ffmpeg smoke review H1. | Scanner regexes need normalized text, while trace/debugging needs the exact original line and timestamp. | Small `LogLine` schema expansion; no scan result schema change. |
| d002 | 2026-05-18 | Normalize only GBS timestamp prefixes and ANSI color escapes. | Real ffmpeg smoke review H1. | The real failure is caused by `[  213s] ` and color codes; stripping broader prefixes could change unrelated logs. | Minimal compatibility risk for existing fixtures. |
| d003 | 2026-05-18 | Support only `Executing(%prep|%build|%install|%check):` as RPM phase markers. | Real ffmpeg smoke review H2. | These are build phases required by the MVP flow; generic `Executing(%...):` would include RPM scriptlets outside build analysis scope. | Correctly sets `current_phase` for real GBS logs without expanding phase semantics. |
| d004 | 2026-05-18 | Trace scan events and command boundaries with both `text` and `raw_text` when available. | Real ffmpeg smoke review trace note; PR #11 follow-up. | Debugging real logs needs normalized matcher input and original raw line side by side, including multiline commands. | Slight trace size increase; no public output schema change. |
| d005 | 2026-05-18 | Reuse `kind: compiler` for assembler diagnostics and mark them with `details.is_assembler`. | PR2 H3 review instruction. | A new `assembler` event kind would force schema, pattern, router, and semantic changes for behavior that the compile collector can already handle. | `.S`/`.s` diagnostics get file/line extraction, compile evidence, and source-to-object cascade mapping without schema churn. |
| d006 | 2026-05-18 | Enforce the final packet token cap in `packet_assembler.py`. | PR2 H6 review instruction. | The assembler is the final packet producer and already owns BudgetPool/truncation accounting; wrapper-only enforcement would bypass those contracts. | `token_budget.used` is recalculated after truncation and `packet_truncated_to_token_budget` records the degradation. |
| d007 | 2026-05-18 | Do not implement H4 pre-build downranking or H5 cascade changes in this hotfix. | Real ffmpeg PR2 validation. | H1/H2/H3 made Top-1 the assembler diagnostic, and existing `.S -> .o` suffix mapping associated the make cascade with an assembler event. | H4/H5 remain deferred; no v0.6 or M9 scope is pulled into the hotfix. |
